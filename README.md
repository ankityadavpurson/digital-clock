# Digital Clock

[Click here](https://digital-clock-1611.web.app/) to see the app

Built with React and [Vite](https://vite.dev/). Requires Node.js 20.19+ or 22.12+.

## Available Scripts

In the project directory, you can run:

### `yarn start`

Runs the app in development mode.<br />
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

The page will hot-reload when you make edits.

### `yarn build`

Builds the app for production to the `build` folder, then writes `build/health.json` for the `/health` endpoint.

### `yarn preview`

Serves the production build locally for a final check before deploying.
